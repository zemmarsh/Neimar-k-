# universal converter

Локальное десктопное приложение на Python для пакетной конвертации, тримминга и обработки медиафайлов без передачи данных на внешние серверы.

Приложение решает задачу безопасной работы с медиаконтентом, автоматически подбирает оптимальный битрейт аудио, позволяет редактировать ID3-теги MP3, проводить обрезку по таймкодам и очищать EXIF-метаданные у изображений.

---

## Технические особенности

- **Локальная обработка и безопасность:** Конвертация происходит строго на машине пользователя через FFmpeg и Pillow, исключая утечку данных.
- **Многопоточность:** Обработка файлов выполняется в параллельных потоках (`ThreadPoolExecutor`), сохраняя отзывчивость графического интерфейса.
- **Контроль качества (Up-sampling protection):** Автоматический анализ исходного битрейта через `ffprobe` перед конвертацией предотвращает искусственное увеличение размера файла без улучшения качества.
- **Очистка EXIF:** Возможность сброса приватных метаданных (геолокация, параметры съемки) при сохранении изображений.
- **Абсолютная автономность:** Автоматическое подключение бинарных файлов FFmpeg при старте приложения без необходимости ручной установки системных утилит.

## Использование
1. Добавление файлов: Перетащите файлы в рабочую область или нажмите кнопку «Выбрать файлы».
2. Настройка и Предпрослушивание:
   - Для аудио/видео: слушайте фрагменты через кнопку «▶ Плеер», нажимайте «💡 Авто» для подбора битрейта, редактируйте «🏷️ Теги» для MP3 или укажите диапазон обрезки (ЧЧ:ММ:СС).
   - Для изображений: выберите итоговый формат и отметьте опцию «Очистить EXIF».
3. Выполнение: Укажите директорию назначения (по умолчанию сохраняет рядом с исходником) и нажмите «🚀 Старт».

## Инструменты и библиотеки

- **Python 3.10+** — основной язык разработки.
- **CustomTkinter & TkinterDnD2-Universal** — современный графический интерфейс с поддержкой темного/светлого режима и поддержкой Drag-and-Drop.
- **FFmpeg (`ffmpeg` / `ffprobe`)** — кроссплатформенная обработка аудио- и видеофайлов, извлечение потоков, тримминг и перекодирование.
- **Pillow (PIL)** — обработка и конвертация графических форматов, манипуляции с метаданными EXIF.
- **Pygame** (`pygame.mixer`) — производительный и лёгкий аудиодвижок для предпрослушивания медиафайлов в интерфейсе.
- **Mutagen** — чтение и запись метаданных/ID3-тегов для аудиофайлов (MP3).
- **Plyer** — кроссплатформенные системные уведомления по завершении конвертации.
- **Standard Library Modules:**
  - `concurrent.futures` — организация пула потоков для параллельной пакетной обработки.
  - `logging` — ротируемое журналирование процессов и ошибок.
  - `subprocess` — низкоуровневый запуск консольных утилит FFmpeg.

## Архитектура и стек технологий
``` text
├── src/ 
    ├── Core.py       # Бизнес-логика, обёртка FFmpeg/Pillow, многопоточность
    ├── GUI.py        # Графический интерфейс (CustomTkinter, TkinterDnD, Pygame player)
    ├── ffmpeg.exe        # Автономные бинарные файлы FFmpeg
    └── ffprobe.exe       # Утилита анализа медиапотоков
├── logs/             # Папка автосоздаваемых ротируемых логов
    └── app.log       # Журнал работы приложения (RotatingFileHandler)
└── requirements.txt  # Список внешних зависимостей Python
```
Основные зависимости
- GUI: customtkinter, tkinterdnd2-universal

- Обработка медиа: static-ffmpeg, imageio-ffmpeg, Pillow, mutagen

- Системные уведомления: plyer

## Наглядный путь работы:
1. Аудио/Видео
``` text
[ Пользователь ] 
       │ (Drag-and-Drop / Выбор файлов)
       ▼
[ GUI.py ]
       │ 1. Анализ типа файлов (detect_file_type)
       │ 2. Предпрослушивание (Pygame) / Редактирование MP3 тегов
       │ 3. Автоанализ битрейта (ffprobe via Core.py)
       ▼
[ ThreadPoolExecutor (Core.py) ] ── (Параллельные задачи)
       │
       ├─► [ FFmpeg Subprocess ] ──► Обрезка (-ss/-to) ──► Извлечение звука/Конвертация
       │                                                              │
       ├─► [ Mutagen (EasyID3/ID3) ] ◄── Запись тегов и обложки ──────┘
       ▼
[ Сохранение результата ] ──► [ RotatingFileHandler (logs/app.log) ] ──► [ System Notification (Plyer) ]
```
2. Изображение
``` text
[ Файл изображения ]
       │
       ▼
[ Core.convert_image() ]
       │
       ├─► Strip EXIF = True  ──► [ Перенос сырых пикселей PIL (Clean Image) ] ──┐
       │                                                                          ├─► [ Сохранение в целевой формат ]
       └─► Strip EXIF = False ──► [ Стандартное сохранение Pillow (With EXIF) ]  ──┘
```

## Ограничения

- **Конвертация видео:** В текущей версии для видеофайлов доступно только извлечение и конвертация аудиодорожки (аудио-экстрактор). Полная перекодировка видеопотоков (H.264, HEVC, AV1) временно не поддерживается.
- **Пакетная обработка тегов:** Редактирование ID3-тегов при конвертации нескольких файлов одновременно применяет одинаковые метаданные ко всему пакету.
- **Зависимость от системных ресурсов:** Скорость параллельной конвертации напрямую ограничена количеством ядер процессора и дисковой подсистемой (SSD/HDD) пользователя.
