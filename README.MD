# 🎵 Audio Converter

Графическое приложение на Python для конвертации аудиофайлов в различные форматы. 

Приложение спроектировано с четким разделением пользовательского интерфейса и логики обработки (архитектура **GUI / Core**). В качестве графической оболочки используется библиотека `CustomTkinter`, а обработка медиафайлов осуществляется путем вызова утилиты `FFmpeg`.

---

## Архитектура и функциональность

* **Разделение слоев:** Логика конвертации (`core.py`) полностью изолирована от графического интерфейса (`GUI.py`), что позволяет использовать ядро в консольных скриптах или интеграциях.
* **Настройка FFmpeg:** Приложение автоматически проверяет наличие FFmpeg в системе, а в случае его отсутствия использует бинарные файлы из пакета `imageio-ffmpeg`.
* **Мультипоточность:** Обработка файлов выполняется в отдельном потоке, сохраняя отзывчивость интерфейса при работе с большими объемами данных.
* **Безопасность данных:** Реализована проверка успешности конвертации и автоматическое удаление поврежденных или нулевых файлов при возникновении сбоев.
* **Пакетная обработка:** Возможность одновременной загрузки нескольких файлов, выбора общего формата, битрейта и директории сохранения.

## Запуск
1. Клонирование репозитория
``` text
git clone [https://github.com/your-username/your-repo-name.git](https://github.com/your-username/MConverter.git)
cd MConverter
```
2. Установка зависимостей
```text
pip install -r requirements.txt
```
3. Запуск приложения
```text
python converter.py
```

## 📋 Поддерживаемые форматы
Приложение работает с большинством популярных аудиоформатов:
- MP3, WAV, OGG, FLAC, AAC, M4A
