Этот проект представляет собой **универсальное десктопное приложение для конвертации аудиофайлов и изображений**. Система спроектирована с акцентом на удобство использования, автоматическую «защиту от ошибок» и асинхронную обработку данных.

Приложение автоматически адаптирует интерфейс под загружаемый контент, подгружает необходимые движки обработки и позволяет легко менять форматы медиафайлов без сложной ручной настройки.

## 📊 Степень завершённости
На данный момент проект представляет собой полностью рабочий **MVP-продукт**. Реализована базовая конвертация аудио (через FFmpeg) и изображений (через Pillow), построена архитектура разделения интерфейса и ядра, добавлена защита от неверного выбора форматов и асинхронный запуск. Проект активно дорабатывается и расширяется новым функционалом.

## ✨ Обзор Системы (Core Concept)
Вместо сложной настройки параметров конвертации под каждый файл, приложение берет рутину на себя:
* **Интеллектуальная защита:** Система автоматически определяет тип загруженных файлов (аудио или фото) и блокирует выбор несовместимых форматов.
* **Асинхронная обработка:** Все операции конвертации вынесены в отдельные потоки, благодаря чему графический интерфейс не зависает даже при обработке больших пачек файлов.
* **Автоопределение окружения:** Приложение автоматически ищет FFmpeg в системе, а при его отсутствии использует встроенные бинарные модули.

## 🏗️ Архитектура Проекта
Архитектура разделена на два ключевых модуля, обеспечивающих четкое разделение графического интерфейса (**GUI**) и логики обработки (**Core**):

### 🧠 1. Модуль Ядра (`Core.py`)
Центральный обработчик логики. Наследует принципы полной изоляции от интерфейса: не содержит элементов GUI и может легко вызываться в консольных скриптах или сторонних интеграциях.

* **Анализ типов файлов:** Функция `detect_file_type()` сканирует расширения переданных файлов и автоматически определяет категорию (`audio`, `image`, `mixed` или `unknown`). Это предотвращает ошибки при попытке смешать разные форматы.
* **Менеджер окружения:** Функции `check_ffmpeg()` и `get_ffmpeg_exe()` осуществляют мгновенную фоновую проверку наличия FFmpeg в системе или пакете `imageio-ffmpeg` без задержек при запуске приложения.
* **Обработка аудио:** Функция `convert_audio_file()` формирует и выполняет команды утилиты FFmpeg для сжатия и смены форматов аудиозаписей с опциональной настройкой битрейта.
* **Обработка изображений:** Функция `convert_image_file()` использует библиотеку `Pillow` для конвертации картинок с автоматической коррекцией прозрачности и альфа-каналов (`RGBA` -> `RGB`).
* **Единый менеджер конвертации:** Функции `convert_file()` и `batch_convert()` выступают универсальным роутером, который самостоятельно выбирает нужный инструмент под каждый файл и выполняет пакетную обработку с передачей прогресса.

### 🎨 2. Графический Интерфейс (`Converter.py`)
Отвечает за визуальное взаимодействие с пользователем, динамическое построение UI на базе `CustomTkinter` и безопасную обработку событий drag-and-drop.

*   **Двухэтапный адаптивный UI:**
    1. *Этап 1 (Загрузка):* Компактная зона сброса файлового потока с возможностью клика или перетаскивания (Drag-and-Drop via `tkinterdnd2`).
    2. *Этап 2 (Настройки):* Окно плавно расширяется и отображает панель управления, подстраиваясь под типы загруженных файлов.
*   **Динамическая защита («От дурака»):** Автоматически скрывает параметры битрейта для графических файлов и несжимаемых аудиоформатов (`WAV`, `FLAC`).
*   **Асинхронный запуск:** Тяжелые компоненты инициализируются с ленивой подгрузкой (`after()`), а сама конвертация выполняется в изолированном потоке (`threading.Thread`), сохраняя отзывчивость GUI.

├── Core.py           # Логика обработки медиафайлов и работы с FFmpeg / Pillow

## Запуск
1. Клонирование репозитория
``` text
git clone [https://github.com/your-username/your-repo-name.git](https://github.com/your-username/MConverter.git)
cd MConverter
```
2. Установка зависимостей
```text
pip install -r requirements.txt
```
3. Запуск приложения
```text
python converter.py
```

## 📋 Поддерживаемые форматы
Приложение работает с большинством популярных форматов:
- Аудио: MP3, WAV, OGG, FLAC, AAC, M4A
- Изображения: JPG / JPEG, PNG, WEBP, BMP, ICO, TIFF
